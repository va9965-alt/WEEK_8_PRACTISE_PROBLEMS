# Week 8 Practice Problems

This repository contains five standalone Java console programs. Each program reads input from standard input and prints its results to standard output.

## Problems

| Folder | Program | Description |
| --- | --- | --- |
| `QUESTION 1` | `Question1` | Applies payment fees for card, wallet, and bank transfer transactions. |
| `QUESTION 2` | `Question2` | Calculates due dates for books, DVDs, and magazines. |
| `QUESTION 3` | `Question3` | Calculates delivery fees for standard, express, and international shipping. |
| `QUESTION 4` | `Question4` | Grades multiple-choice, true/false, and essay questions. |
| `QUESTION 5` | `Question5` | Calculates fares for bus, train, and metro journeys. |

## Requirements

- Java 8 or newer

## Compile and run

In PowerShell, for example, compile and run Question 1 with:

```powershell
Set-Location "QUESTION 1"
javac Question1.java
java Question1
```

Enter the input requested by the program. Use the corresponding folder, source file, and class name for the other questions.
