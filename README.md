# Week 8 Practice Problems

This repository contains five standalone Java console programs. Each program reads its input from standard input and prints its result to standard output.

## Problems

| Folder | Program | Description |
| --- | --- | --- |
| `QUESTION 1` | `Question1` | Calculates payment amounts with fees for card, wallet, and bank transfer payments. |
| `QUESTION 2` | `Question2` | Calculates library due dates for books, DVDs, and magazines from a fixed current date. |
| `QUESTION 3` | `Question3` | Calculates delivery fees for standard, express, and international shipping. |
| `QUESTION 4` | `Question4` | Grades multiple-choice, true/false, and essay questions. |
| `QUESTION 5` | `Question5` | Calculates fares for bus, train, and metro journeys. |

## Requirements

- Java 8 or newer

## Compile and run

Run each program from its question folder. For example, in PowerShell:

```powershell
Set-Location "QUESTION 1"
javac Question1.java
java Question1
```

Enter the input requested by the program. Use the matching class and source filename for the other folders.
